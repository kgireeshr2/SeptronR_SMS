# 08 — Print Production Checklist (A4 Tri-Fold)

Use this checklist before sending the brochure to print.

## Document setup
- Size set to A4 landscape (297 x 210 mm)
- Tri-fold guides correctly placed
- 3 mm bleed added on all sides
- Safe margins maintained inside each panel
- Fold-in flap panel slightly narrower if printer requests roll-fold adjustment

## Content checks
- Company name: SeptronR
- Tagline: A leading tech solution
- Phone numbers: 9490426524, 7416123742
- Address: Banglore 560036
- Website: https://septronr.com
- Mobile app section clearly visible
- Core SMS features clearly listed
- CTA appears on front and back panels
- QR code is scannable and tested

## Visual checks
- Product screenshots are high resolution
- Icons are consistent in style
- Text contrast is readable on print background
- No overcrowded text blocks
- Headings are visible from distance

## Export checks
- Color mode CMYK
- Export format PDF Print / PDF/X
- Fonts embedded or outlined
- Image compression set to high quality
- Bleed and crop marks enabled (if printer requires)

## Final proof checks
- Check panel order (outside and inside) one last time
- Print one sample on office printer for fold test
- Confirm phone number and website are error-free
- Confirm all spellings in headings and CTA
- Send print-ready + editable source file to vendor

## Recommended first batch
- Quantity: 500
- Paper: 170–250 GSM art paper
- Finish: Matte lamination for premium look
